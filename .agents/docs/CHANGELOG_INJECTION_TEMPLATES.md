# 角色提示词注入模板自定义管理系统 - 功能更新日志 (对比 2.8 版本)

本日志梳理了相比 2.8 初始版本 (`b1a5770`) 所完成的全部功能增强、架构重构与逻辑修复。

---

### 1. 提示词注入模板自定义管理系统 (Preset CRUD Management)
- **多预设方案生命周期管理**：支持在前端界面中独立创建、重命名、修改保存、另存为及删除注入模板方案。
- **内置 3 大预置模板方案**：
  - **默认方案**：基于 2.8 经典中文分割标注原生态字段格式。
  - **Tavern XML 格式**：采用 `<character>` 与 `<common_outfit>` 标签包覆，专为 LLM 上下文结构化识别设计。
  - **Markdown 极简卡片**：采用标准 Markdown 列表与卡片排版，简洁高效。
- **系统方案防护与复原**：系统内置预置方案不可删除与重命名，并支持一键恢复初始内容。
- **方案 JSON 导入导出**：支持对单项 Preset 方案进行独立的 JSON 导入、导出及格式校验。

---

### 2. 智能解耦注入引擎与空变量处理 (`applyInjectionTemplate`)
- **动态模板替换**：由原静态字符串拼接重构为基于模板占位符（如 `{nameCN}`, `{traits}`, `{facial}` 等）的动态渲染引擎。
- **单变量/全空行精简擦除**：某行模板中的占位符变量为空或空白时（例如未配置的 `负向提示词：{negative}`），引擎会自动丢弃整行文本，避免产生无意义前缀与 Token 浪费。
- **多变量同行注入与对齐**：一行包含多个变量时（如 `- 五官: {facial} | 背面: {facialBack}`），若部分有值部分为空，空变量注入 `null`（输出 `- 五官: 大眼睛 | 背面: null`），确保多列卡片排版对齐。
- **孤立标题擦除**：若列表清理后无下方实际内容，顶部关联标题行（如 `服装列表：`）自动清理不输出。

---

### 3. 正文触发匹配与多别名精准对齐 (`isCharacterTriggered` & `getTriggeredCharacterName`)
- **多别名拆分支持**：`nameCN`、`nameEN` 及 `triggers` 字段支持使用 `|` 竖线分隔多个别名（如 `爱丽丝|Alice|小爱`），引擎自动解析为别名数组。
- **上下文正文触发**：联动世界书与聊天记录正文，仅当提及角色别名或触发词时才触发对应 Prompt 注入。
- **自定义触发词补全**：修复调试分析工具中对 `character.triggers` 的检索逻辑，确保 Prompt 注入与调试工具检测结果 100% 保持一致。

---

### 4. 编辑器交互与实时预览优化
- **焦点感知与快捷插入**：自动感应用户当前焦点的模板输入框，提供下拉选择框一键插入常用占位符变量。
- **主题感知的 Live Preview**：实时 Mock 效果渲染框无缝继承 SillyTavern UI 主题字体与色彩变量 (`--SmartThemeBodyColor`)。
